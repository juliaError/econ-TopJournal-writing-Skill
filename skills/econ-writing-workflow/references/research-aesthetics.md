# 经济学研究选题的判断与校准

v0.8 · 试用稿。供提出候选题、选择主问题或实质性改题时调用。作者已经指定题目、只要求解释一项机制或推导一个结果时，直接回答指定问题。

## 怎样提出和筛选 idea

1. **先找值得解释的现象。** 先用普通语言写出谁面临什么处境、我们还不理解什么，以及答案不同会改变谁的判断。政策、企业、家庭或社会都可以是观察的出发点。描述重要事实的论文，可以从两种对该事实含义的解释入手，无须虚设一项政府决策。
   先设想论文已经做完，结论可能是甲，也可能是乙。两种结论，会让我们对谁的处境、哪项制度或哪个重要现象产生实质不同的判断？如果结论翻过来，我们在意的事情几乎没变，这个张力就不足以撑起主问题。
   题句要让读者看见当事人的处境和选择。问“哪些人”时，点出真正会改变选择的差别。写完后再核对，例子解释到了题句承诺的哪一步。
2. **分清主问题和局部问题。** 给候选题排序前，先问：如果前面那项尚未决定的选择换一个答案，这个细节还值得单独研究吗？若它只在选定一种做法后才有意义，就先比较该做法和现实中的其他选择，再把细节放回相应情形。若这个细节足以改变哪种做法更可取，就用它来回答主问题。例如，讨论何时定标，可能已经给定采用哪条路线、伙伴国会不会加入。如果这些尚待解释的选择决定了大部分经济后果，应先研究它们。按“能独立成篇 / 适合做篇内机制或小节 / 目前搁置”作出判断并说明理由。一个具体的小切口，只要能区分对重要现象的两种解释，也可以支撑整篇论文。
   **看机制能覆盖哪些人。** 先说想解释哪类人的哪个重要选择，再列出机制起作用必须同时满足的条件。区分可以各自出现的条件和必须同时出现的条件，也区分事前需要有这种可能与事后确实发生。若多项条件的交集才是机制的适用人群，说明这个较窄的情形为何足以改变对更大问题的认识，或为何对这群人本身后果重大。理由不足时，把它放回更大问题下作为一个具体机制。实际覆盖程度缺乏证据时标为待核。研究中用来识别效应的窄样本另行判断。
3. **说明经济力量如何改变答案。** 对理论或政策题，写出当事人面临的可行选择，谁得到收益、谁承担损失，另一方会怎样回应，以及哪项条件能改变选择的排序。对事实题，写出哪种事实能区分两种解释。“重复试验提供的信息少”只有一个方向。在同一项安排下，今天的收益如何改变明天的选择，或不同当事人的利益如何分化，才可能使原判断发生变化。
   **与最有竞争力的现实替代方案比较。** 固定两种安排都能提供的东西，指出哪项实际决策、激励或收益归属仍有差别，并允许另一方案在现实中能做到的改进。如果同一个理由也能解释选择另一方案，继续找能区分两者的条件；找不到时，降低原解释的权重。例如长期服务合同也能让同一名工程师驻厂，解释客户直接聘用时，还要说明哪项工作由客户安排会做得更好，以及承担培训的设备商为何愿意配合。
   **先查选题赖以成立的现实前提。** 若主要结论取决于一项制度或做法，先核对它在目标行业和人群中是否实行、覆盖多少。可研究尚未实施的政策，但须说明为何值得现在研究；缺乏这个理由时先作备选。提出反直觉行为时，优先给一个能核查的真实案例，写清谁做了什么。个案可以表明行为发生过；要讨论是否普遍，另找覆盖证据。若眼下只查到相邻事实，交代案例能支持哪一步，把动机和效果留作研究假说。
4. **单独判断研究者能知道什么。** 区分当事人知道、研究者有渠道取得、现有材料足以支持的推断。谈数据时说明来源、能观察到的对象和仍缺的连接。纯理论题允许私人信息和不可观察的状态；需说明它怎样影响比较，在哪些条件下结论会失效。暂缺证据时，可以保留重要问题，并降低对实证可行性的判断。容易得到的数据也不能给小问题增加分量。
5. **运用文献检验增量。** 先判断基准研究已经解释了什么，再问改变对象后哪些假设确实影响主判断。选题阶段标出待核之处。进入建模时分别核对最适合作基底的论文，以及最可能已得到该结论的论文。候选题进入正式研究以前再做文献和证据核验。

## 运用经济学理论深化研究问题

**何时使用。** 已有候选想法、需要进一步深化时，运用本节。先保留作者关心的核心现象，再从主体、选择、信息和约束出发，把具体想法联系到经济学理论，找出初稿尚未解释、但足以改变主要结论的问题。

### 理论参考表

以下是分析入口，包括但不限于这些方向，也允许采用表外更合适的理论。每次选择最贴合问题、最有解释力的一两个方向，不要求逐项套用。

| 理论方向 | 可以帮助追问什么 |
|---|---|
| 企业边界、交易成本 | 一项活动为什么通过市场交易完成，或者转由企业内部组织？ |
| 不完全契约、产权与议价 | 哪些事情不能事先约定？决策权和收益归属怎样改变双方的投资？ |
| 委托代理、多任务激励 | 谁替谁行动？哪些行为难以观察？奖励一项表现，会不会挤压另一项重要工作？ |
| 信息不对称、信号与筛选 | 谁掌握什么信息？其行为会透露还是隐藏信息，并怎样改变其他人的选择？ |
| 不完全竞争、战略互动 | 企业改变定价、进入或产品选择后，竞争者怎样回应？这种回应会不会改变原结论？ |
| 外部性、公共品与协调 | 当事人的私人收益和社会收益为何不同？各自合理的选择为什么可能产生较差的共同结果？ |
| 人力资本、匹配与家庭分工 | 谁承担投资成本，谁取得回报？流动机会、匹配质量或家庭分工怎样改变投资意愿？ |
| 动态投资、不可逆性与学习 | 当前选择怎样改变未来的信息、资源和可行选择？哪些机会一旦放弃便难以恢复？ |
| 政治经济学、集体行动 | 谁推动或阻碍一项制度？利益的集中程度和组织能力怎样影响最终政策？ |

### 怎样运用理论推进问题

先说明本题与所选理论的具体联系：谁在作什么选择，受到什么约束，哪一种经济力量会改变选择。再判断该理论已经解释了什么，还留下什么重要问题。理论名称后必须接具体的经济推理。

说明本题的哪些现实条件会改变既有理论中的行为、方案比较或结论，由此提出一个比初稿更有分量、也更明确的研究问题。若不同理论对同一现象给出不同解释，指出什么条件或事实可以区分它们。若只是重述经典结论，应如实说明；尚未核对文献的增量，保留为待验证判断。

最终用清楚的语言写出：理论帮助我们发现了什么，为什么这一步值得研究，以及它怎样改变原来的判断。找不到实质推进时，说明当前最需要核实什么，不用增加术语、变量、参与者或政策细节制造深度。

### 案例：从工程师转聘到企业边界

**原来的想法。** 设备商出资培养工程师，客户随后把人聘走。初步解释是，客户需要工程师持续调试设备，工程师转入客户企业可能有利于设备采用和后续采购。这是候选解释，设备商是否主动促成转聘及其动机仍待核实。

**作者的追问。** 长期服务合同同样可以让工程师驻场。持续调试能够解释为什么需要技术服务，却还没有解释为什么要改变雇佣关系；设备商已经承担培养成本，又为什么愿意让客户把人聘走？

**经济学理论的联系。** 作者想到科斯的企业边界问题：持续调试这项活动，为什么有时由设备商通过服务合同提供，有时由客户在企业内部组织？这里需要解释的是调试职能及其决策权由谁组织。把这一选择说清楚，才能比较市场交易和企业内部协调各自的成本与收益；仅给人员流动贴上“企业边界”的名称还不够。

**进一步研究什么。** 比较两种安排怎样影响调试任务的安排、客户的设备投资，以及设备商回收培训投入的能力。允许服务合同具有现实中可行的改进，再考察是否仍有影响组织方式选择的差别。若改进合同已经能实现同样的协调和激励，单凭持续调试的需要就不能解释转聘；若仍有差别，则说明是哪项现实条件使活动转由客户内部组织更有利，以及设备商为什么愿意配合。这些问题为进一步建模提供方向，并不预先认定转聘更有效率。

本例保留的是从具体想法转向经济学问题的分析过程，不要求其他题目也寻找合同或企业边界。

### 判断是否真正深化

理论联系必须帮助提出或解释一个重要问题。比较深化前后：新增分析多解释了哪项选择，哪项预测、方案排序或成立条件因此改变；删去新增内容，会失去哪一个判断。若这些没有变化，只增加理论名称或把原意展开得更长，就尚未形成实质推进。能否构成文献贡献，还须回到最接近的原文核对。

## 用讨论案例校准分寸

| 原来的想法 | 作者的取舍 | 下次怎样用 |
|---|---|---|
| 国际标准。越早定标越有利于配套投资，也越容易锁定路线。 | 作者认为定标时机在本题属二阶。更重要的是我国推动哪条路线、伙伴国愿不愿意加入。我国企业可能在更小的共同市场里取得更大份额。路线确定以后再讨论规范写多细。帮助兼容的信息如果也能帮助改进核心产品，扩大市场才同时伴随技术追赶。 | 先找决定市场大小与竞争方式的选择。若时机本身能改变谁加入、进而决定哪条路线能生存，允许它成为另一篇论文的主问题。后一情形是用于检验规则的假设。 |
| 应用场景。新试验比重复试验多提供多少信息，适合放在投入强度下讨论。 | 作者提出开辟新用途与替代传统技术的社会后果不同。技术替代会使传统工人和企业受损，但同一替代过程带来的销售收入又能为新用途融资。政策该先支持哪一种应用，由此成为重要问题。企业可能掌握试验结果，外部研究者未必有记录；即使有结果，也不能直接观察企业因此学到了多少。 | 分别评价经济问题的分量与证据可得性。问清一个被算作当期损失或收益的过程，会不会改变下一期的可行选择。 |
| 基础研究。助手提出由平台研究企业是否应联合悬赏，又提出考察出资企业能占有多少研究回报。 | 同轮反馈中，作者把是否联合留给企业，认可用可占有回报分析“基础研究专利”。保护过短可能无人率先出资，保护过长又会延迟后续利用，甚至引起重复研发。 | 一对正反效应本身不足以决定选题。先问谁有权决定，然后问同一个制度选择是否改变前后两方的行为。制度设想出自作者，其效果是待研究问题。 |
| 产学研。助手提议用何怡瑶、潘士远的模型解释教师参与企业合作的意愿。 | 作者回到原论文已有的基础研究与应用研究人员配置，要求核查未来产业的高不确定性、突破后较高的回报和长周期分别怎样改变资源配置与资助判断。他也质疑为长周期引入两道时间间隔有何必要。 | 删除拟增设定，看会失去哪项经济判断。现实里能细分的两个环节，可以在模型里合并。 |
| 祖辈照料。①研究照料安排怎样改变父母的迁移与就业；②、③分别研究一家的生育或入园怎样改变另一家的生育时点或复工。 | 作者认可三题有意义，尤其认可①。②、③都要有两户可能依靠同一位老人，照料需要在时间上有关联，老人也要能在两户间提供照料。作者最终强调的是这些条件共同限制了适用人群，明确认可生育与复工本身的重要性。 | 逐项检查限制能否放宽。例如老人可跨地轮流照料，两家住在同城便不是必要条件。②关心两家能否错开生育，若只观察已经同期生育的家庭，反而会遗漏机制所预言的推迟。 |
| 企业培训。①讨论员工提前离职偿还培训费与收入差距，②问设备商为何可能愿意让客户聘走自己培养的工程师。 | 作者把①列为备选，认为制度的现实覆盖影响优先级。更看好②的反直觉问题，并要求优先配真实案例。 | 核查时分开“员工去了客户那里”“设备商愿意促成转聘”“客户因此增购设备”。嘉腾机器人的访谈提供第一步的线索，高管也说到人才流失的负担。工程服务商与客户商定转聘的案例能支持第二步在邻近行业确实发生。设备商为扩大销售而主动转出人员仍需直接证据。 |
| 务工路费。助手起初更看好“路费先给谁”，因为最缺粮的家庭也可能最等不起第一笔工钱。 | 作者更看好“同一笔预算，补路费还是直接给现金”。直接发的钱也能买票，限定外出才能领钱的理由还需要解释。 | 把“谁等不起工钱”带回两种做法的比较：这个细节能说明限定外出会漏掉谁，进而改变救助方式的选择。 |

## 一轮训练怎样进行

仅在作者明确要求训练或盲评时使用本节。

- 同一个现实背景下提出二至三个真正值得考虑、结论有区别的题目。每题展示主问题、会改变答案的理由、现实中能看到什么。篇幅相近，作者也可以全否或自行改题。展示前另存助手的取舍、理由与最不确定的一点，待作者评价后再揭示。
- 请作者先指出最想做和最想放弃的题，以及决定取舍的那一步。收到反馈后逐项对照助手的事前判断，保留作者原话。区分题目重要性、证据或文献障碍、个人研究兴趣。若两种解释会导向不同修改，只追问最有区分度的一点。
- 根据偏差提出一条具体修订，留下旧判断作为对照。下一轮先用同一材料提出更好的题，检查有没有修正错误；随后换材料，让助手在看到作者意见前作出新判断。如果新题再次暴露问题，记录反例，缩小规则的适用范围。作者认可且在新材料上有辨别力的判断，再提议进入正式技能。
- 盲评阶段将助手的排序留到反馈之后。交给 idea 打磨器做正式评估时，接回已有的创新性、清晰度、可行性、解题能力、重要性判断；交给 model partner 时，传递作者选中的主问题、竞争机制、基准和待核条件。后续回合复用同一版材料，升级时保留原版本和作者的理由。
